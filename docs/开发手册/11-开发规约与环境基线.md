# 11 · 开发规约与环境基线（持续更新，2026-09-17/18 实测校准）

> 每次开发前必读。这里固化的是 45 天开发里**踩过坑才换来**的约束：依赖矩阵、启动/测试流程、实测数据口径、已证伪口径、已知限制。

## 一、依赖矩阵（硬约束）

| 包 | 锁定版本 | 备注 |
|----|---------|------|
| langchain | ==0.3.27 | 0.3.x 系列整体 |
| langchain-core | ==0.3.86 | |
| langchain-community | <0.4 | |
| langgraph | >=0.3,<0.4（实测 0.3.34） | |
| langchain-openai | >=0.2,<0.4（实测 0.3.35） | 2026-09-18 补锁 |
| langchain-chroma | <0.3 | |
| chromadb | ==1.3.7 | 升级前须验证段文件落盘 |

### 为什么锁这么死：两次 1.x 漂移事故

1. **langgraph 1.x 混入** → 拉 langgraph-sdk 0.4.x → import core 0.3.x 不存在的 `chat_model_stream` → ReAct 图构建 ModuleNotFoundError → **静默回退规则 Agent**，连带 sentence-transformers 校验 ValueError，表面是 6 例测试失败，实为环境漂移；
2. **langchain-openai 升到 1.4.2** → import 不存在的 `ContextOverflowError` → ChatOpenAI 构造失败 → `get_llm()` **静默回退 DemoLLM**（回答秒回但全是模板话）。

**新环境/换机固定动作**：`pip install -r requirements.txt` → `pip show langgraph` 核对 0.3.x → `type(get_llm()).__name__` 必须是 `ChatOpenAI`。

## 二、启动与测试基线

```bash
pip install -r requirements.txt
uvicorn serve.main:app --port 8008     # 或 start.bat（纯 ASCII，CRLF）
pytest tests/                          # 82 例全离线，基线 ~25s
```

- 测试零外部依赖：`tests/fakes.py` 用 FakeCollection/FakeVS 替代真实 ChromaDB 与 BGE——**不需要 API Key / 向量库 / 本地模型**（吃 v1.0 降级设计 + v2.0 DI 容器 override 的红利）；
- 批量上传期间不要并行跑 pytest（chroma 写锁）；
- `.env` 与 `config/model_config.json` 含 Key，均在 .gitignore 内；**API Key 不写入任何文档/仓库**。

## 五、开发规约（踩坑换来的十条）

1. **降级优先**：所有外部依赖带演示兜底，无 Key 离线可跑；但降级必须可探测（`type(get_llm()).__name__` / error SSE / 启动自检）；
2. **先测量再动手**：`-X importtime`、bench 脚本、跨进程读数——直觉与规划值一律先实测；
3. **静默失败是头号敌人**：跳过必须显式上报（unsupported 字段 / WARNING 日志），`continue` 前先想「用户怎么知道」；
4. **外部状态跨进程验证**：chroma 进程内缓存假象（06 篇）；
5. **kb_id 构造期固定**：检索器按 kb 实例隔离，缓存键必含 `kb_id`（+ 语料 epoch）；
6. **JSON 持久化一律原子写**（临时文件 + `os.replace`），配并发测试；
7. **客户端可控 ID 与身份绑定**（session_id 绑定、kb_id 格式校验、role 不由客户端指定）；
8. **启动脚本纯 ASCII**（.bat/.sh），失败分支 `pause`；
9. **改 .env 先备份 `.bak-日期`**，改后逐通道探针验证；
10. **不确定的数字先实测再落笔**；同一口径改动要全文档同步（简历/README/项目文档）。

## 六、已知限制（如实记录，不掩盖）

- `.doc`/`.xlsx` 为纯文本粗提取，不还原表格排版；1 份 WPS 文件有二进制噪点（文件流本身问题，刻意不加启发式过滤器，由审核流兜底）；
- chromadb 锁 1.3.7，升级需在目标机验证段文件落盘；
- 上下文压缩 LLM 摘要模式未实测（需线上 Key 观测质量）；
- embedding 迁移到真实 1024 维需**全库重建**，挂起待定；
- UI v4.0 P2 剩余（文档列表表格化、知识库卡片徽章、问答容器输入区）与 P3 未启动。
