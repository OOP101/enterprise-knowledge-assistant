## 二、项目现状速览（2026-09-18）

- **规模**：202 文档 / 2086 分片在库（语料 237 份，.doc/.xlsx 已支持）；9 个知识库（8 部门 + default）；
- **质量**：pytest 75 例全离线通过（含 15 审核流 + 11 安全 + 8 格式扩展回归）；冷启动 2.4s；
- **形态**：FastAPI 单服务（8008）+ 原生 JS 单页前端（浅色科技蓝主题）+ ChromaDB；
- **主模型**：deepseek-v3 @ 阿里百炼（OpenAI 兼容），运行时在线热切换，无 Key 全链路演示兜底。

## 四、几条贯穿全程的主线

1. **降级优先**：从 v1.0 起所有外部依赖（LLM/Embedding/Reranker）都带演示兜底，无 Key 离线可跑——测试 75 例全离线通过正是吃这条红利；
2. **先测量再动手**：流式 30s 卡顿（05 篇）、冷启动 17s（09 篇）、压缩率 21%（11 篇）都是实测推翻直觉/规划值的案例；
3. **静默失败是头号敌人**：静默跳过 36 份文档（08 篇）、DemoLLM 静默兜底（10 篇）、SSE 空回答事故（05 篇）——修复方向统一是"显式上报"；
4. **跨进程验证外部状态**：chroma 不落盘假象（06 篇）、模型配置漂移（10 篇），进程内"看起来正常"不可信。
