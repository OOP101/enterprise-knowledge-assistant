## 一、项目概述

将企业 SOP、技术文档、规章制度转化为可查询的知识库，员工提问即可秒级获取标准答案。**2.0 升级为可观测、可评估、可扩展的多知识库 RAG 平台**：真实语义检索 + 可插拔重排序 + LLM Agent 工具闭环 + 长期记忆 + 真流式 + 认证权限 + Eval 评估体系。**3.0 新增入库审核流**：AI 预筛打分 + 人工把关 + 双层存储，过审才进检索索引。

---

## 二、项目背景

企业内部制度、流程、技术文档分散，员工查找标准答案耗时且口径不一。传统搜索无法理解语义，新人上手依赖口口相传。本项目用 RAG + LLM 重构知识获取链路，实现：

1. **查得到**：多知识库语义检索，跨部门制度可溯源
2. **答得准**：检索 + 重排 + 上下文压缩，LLM 基于原文回答带来源
3. **办得了**：问答 → 流程发起（请假/加班/报销/入职）闭环
4. **管得住**：入库审核流过滤低质文档，RBAC 按部门隔离知识库

## 六、架构设计

**检索链路**：`提问 → 热查询缓存检查 → 查询改写(LLM/规则) → 指代消解 → Dense + Sparse 混合检索 → RRF 融合 → BGE-Reranker 精排 → 上下文压缩(Token预算) → LLM 生成带来源回答 → 写入缓存 → 记录Token用量`

**入库链路**：`文档 → 加载解析(表格转Markdown) → 两阶段清洗 → 智能切片(500/overlap50) → Embedding → 向量库 Upsert（按 doc_id 增量更新）→ 清空查询缓存`

**审核链路（v3.0）**：`上传 → AI 打分(0-100) → 达阈值直接生效 / 低分挂起 → 人工 approve(重切片带标注入库) / reject(移出索引) → 标注分片检索加权 RRF×(1+0.2)`

**架构升级（v2.0）**：依赖注入容器消除全局单例 + 循环 import；端口与适配器抽象实现可插拔；结构化日志 + request_id 全链路追踪。

## 八、踩坑记录

1. **chromadb 不落盘（最有价值）**：1.3.x/1.5.x Windows 后台压缩器不落盘向量段文件，重启后 `Error constructing hnsw segment reader` 检索全挂。诊断关键：chroma 同进程按路径缓存实例，进程内"读回正常"全是假象，**必须跨进程验证**。修复三层：启动自愈回填（2086 分片全恢复）+ 锁 `chromadb==1.3.7` + 重建脚本改 100 条/批。
2. **向量维度不匹配（两次，方向相反）**：collection 维度创建时锁定，切 embedding 必须清库重建（512↔1024 各踩一次）。
3. **回答不一致**：TEMPERATURE=0.2 + demo 重排 + 多制度定义冲突 → temperature 降 0.0 + 提示词加冲突规则。
4. **start.bat 闪退**：UTF-8 中文注释被 cmd 以 GBK 解析打碎 → 纯 ASCII + 失败加 pause；约定 start.bat/start.sh 永远只写 ASCII。
5. **多知识库串库**：共享 retriever 单例被并发改 kb_id，A 查到 B 部门库 → kb_id 构造期固定 + 缓存键含 kb_id + 每库独立实例，借此重构 DI。
6. **流程图文字提取不到**：文字在 `w:txbxContent`/SmartArt `a:t`，python-docx 读不到 → `_extract_drawing_text()` 兜底。
7. **LangGraph 坑**：`add_conditional_edges` 调 get_type_hints，TypedDict 定义在函数内部报 NameError → 提到模块顶层。
8. **思考模型三大坑**：强制 temperature=1.0、思考 token 吃掉 max_tokens 致空回复、`reasoning_content` 是独立字段。「切回 deepseek-chat 但 Key 是小米的 → 回答全部静默为空」事故 → 新增 error SSE 事件显式上报。
9. **意图分类误判**：「请假流程」纯咨询被判成 action 导致非流式 → `_refine_llm_intent()` 规则后置校验。
10. **.doc 解析**：olefile + FIB piece table 按片解码（cp1252/UTF-16LE），31 份全提取成功；WPS 生成文件混有二进制噪点，**不加启发式过滤器**（会误删真实表格），改由审核打分器按文本密度低分挂起。

## 快速开始

详见 [`README.md`](../README.md)。核心步骤：

```bash
pip install -r requirements.txt
cp .env.example .env   # 填写 LLM_API_KEY / EMBEDDING_API_KEY（留空自动演示模式）
uvicorn serve.main:app --reload --port 8008
```

访问 http://localhost:8008/docs 查看 Swagger。
